# 🛒 NxT Mall

A modern e-commerce web application built with React, FastAPI, and PostgreSQL.

## 🎯 Goal

The goal of **NxT Mall** is to build a modern, user-friendly e-commerce platform where users can browse products, manage their cart, and place orders efficiently.

## 🚀 Tech Stack

- **Frontend:** React
- **Backend:** FastAPI
- **Database:** PostgreSQL

## ✨ Features

- User Authentication
- Product Browsing
- Product Search
- Shopping Cart
- Order Management
- Admin Product Management

## 📁 Project Structure

```text
NxT-Mall/
├── frontend/     # React
├── backend/      # FastAPI
└── README.md
```

## ⚙️ Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
